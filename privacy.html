Privacy Policy — Studies Sync

Last updated: 12 November 2026

What the app accesses

With the user's consent, Studies Sync uses read-only Google OAuth scopes to read:

  • Google Classroom: the list of courses the user is enrolled in, announcements, coursework, course materials, topics and teacher names.
  • Google Drive: files attached to those Classroom posts, which are downloaded so they can be read offline.

How the data is used

The data is saved only on the user's own computer, where it serves as personal study material. It is not uploaded to any server run by the app, sold, shared with third parties, or used for advertising. The app has no backend.

Storage and deletion

The OAuth token and downloaded files are stored locally on the user's device. Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local folder removes all stored data.

Google API Services User Data Policy

Studies Sync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
